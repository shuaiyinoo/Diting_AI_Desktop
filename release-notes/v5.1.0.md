# Diting AI Desktop v5.1.0 更新

> 本次更新是 Diting AI Desktop 迄今为止规模最大的版本升级，涵盖 **远程控制、内置终端、模型配置中心化、多语言国际化、Agent 面板布局、对话富内容渲染、启动过场动画、自动更新系统、磁盘管理** 等数十项新功能和数百项优化。

---

## ✨ 新功能

### 🌐 Diting Cloud 账户与远程控制

- **Cloud 账户系统** — 新增登录 / 注册 / 退出功能，Token 通过 Electron `safeStorage` 加密存储到 `~/.diting/cloud/auth.json`，所有后端 HTTP 请求由主进程发起，前端不直接调用后端接口。
- **远程控制（受控端）** — 桌面端登录后可生成 6 位连接码，手机端输入连接码即可远程查看并控制本机桌面。通过 WebRTC + STOMP 信令实现实时屏幕镜像与远程输入。
- **隐藏窗口架构** — 屏幕采集（`desktopCapturer`）和 `RTCPeerConnection` 编码由独立隐藏窗口承载，主窗口关闭或最小化时远程会话不中断。
- **远程输入驱动** — 基于 `node-enigo` 实现跨平台鼠标 / 键盘 / 滚轮输入模拟，鼠标移动使用背压感知的消费者循环，保证光标实时跟手、不堆积延迟。
- **多屏坐标映射** — 自动采集显示器拓扑，副屏位于主屏左侧时坐标偏移自动校正，解决远程控制最常见的点击偏移问题。
- **屏幕捕获权限** — macOS 屏幕录制权限检测与引导、Windows UAC 兼容、Linux X11/Wayland 降级提示，三端权限差异统一封装。
- **WebRTC 内网优化** — 关闭 Chromium 默认的 mDNS 本机 IP 隐藏，确保内网场景下两端可直连。
- **设置面板远程控制入口** — 设置 → 通用设置中新增「Diting Cloud 账户」和「远程控制」分区，展示登录状态、服务端连接状态、远程镜像开关、会话码及错误提示。

### 📱 多端流式同步

- **流式同步服务** — Chat / Agent 对话的流式输出（token、thinking、tool 事件）实时旁路推送到 Cloud 后端，手机端可实时查看桌面端正在进行的对话。
- **代发请求** — 手机端可通过 Cloud 后端向桌面端发起消息发送请求，桌面端收到后走正常 SSE 流程并将结果同步回手机端。
- **数据同步** — 订阅 Cloud 后端的 sync 请求，本地查询工作区 / 会话 / 消息等数据后通过压缩传输回手机端。
- **登录即连接** — 应用启动时若 Token 仍在有效期内，自动建立远程信令 STOMP 连接，无需用户重新登录。

### 🖥️ Agent 内置终端

- **伪终端服务** — 基于 `node-pty` 创建跨平台伪终端进程，支持多终端实例、工作目录设置、尺寸调整和进程销毁。
- **xterm.js 集成** — Agent 代码编辑器下方新增可折叠的终端面板，支持多标签页、新建 / 关闭终端、xterm.js 全功能终端模拟。
- **终端与编辑器联动** — 终端默认工作目录优先使用当前 Agent 会话路径或项目路径，终端面板高度可拖拽调整。
- **IPC 双向通信** — 前端 xterm.js `onData` → IPC → pty 进程 → shell；shell 输出 → pty `onData` → IPC 事件 → 前端 xterm.js 渲染。

### 🎯 模型配置统一管理中心

- **设置中心化** — 语音、OCR、向量三个模型配置全部收归设置页面，消除散落在各处的硬编码模型路径，应用各模块通过统一配置读取链路获取用户选择的模型。
- **OCR 模型配置** — 新增设置 →「OCR 模型配置」面板，支持下载和管理 PaddlePaddle PP-OCRv3~v6 全系列共 24 个模型预设，模型统一存储到 `~/.diting/model/ocr/`。
- **向量模型配置** — 新增设置 →「向量模型配置」面板，支持下载和管理本地向量嵌入模型，内置 Fast / Balanced / Quality / Multilingual 四档预设，支持自定义 HuggingFace ONNX 模型 URL。
- **模型预热验证** — 向量模型选择时增加推理验证机制，确保模型文件完整可用后再写入配置并触发后续向量化。
- **下载兜底策略** — 模型下载支持自动判断网络环境，直连 HuggingFace 失败时自动切换国内镜像（hf-mirror.com）兜底下载。
- **数据一致性保障** — 切换向量模型时自动清空旧向量索引和关键词索引，重置文件状态为待处理，防止不同维度向量混用。
- **OCR 全链路改造** — `InvoiceOcrService` 和 `OcrWorkerManager` 均改为从本地模型路径加载，用户选择的 OCR 模型通过环境变量注入子进程。

### 🌍 多语言国际化（17 种语言）

- **17 种语言** — 新增简体中文、繁体中文、英文、日文、韩文、法文、德文、俄文、西班牙文、泰文、越南文、土耳其文、葡萄牙文、阿拉伯文、意大利文、印地语共 17 种语言界面。
- **1700+ 条翻译** — 每种语言约 1,700+ 条翻译条目，覆盖所有用户可见的 UI 文本。
- **语言自动检测** — 首次启动时根据系统语言自动选择界面语言，用户可在设置 → 外观中随时切换。
- **语言切换即时生效** — 切换语言后界面立即刷新，无需重启应用。

### 🎬 启动过场动画

- **视频过场页面** — 应用启动时先显示过场动画窗口，播放 `diting_loading.mp4` 视频作为背景，待主窗口页面渲染完成后自动切换。
- **品牌信息展示** — 过场页面左上角展示产品标题、副标题、功能描述和 Tips，带渐变遮罩设计感。
- **版权声明** — 左下角标注视频素材版权来源。
- **播放策略** — 视频播放一遍即停，不循环；视频加载失败时自动降级为旋转动画作为备用。
- **启动流程优化** — 主窗口延迟显示（`show: false`），移除强制全屏 `setBounds`，窗口尺寸回归 config 控制（默认 1100×800）。

### 🔄 自动更新系统

- **状态机式更新流程** — 重写 `electron-updater` 集成，支持 idle → checking → available → downloading → downloaded 全状态流转。
- **后台静默下载** — 检测到新版本后自动后台下载，下载完成后在状态栏显示更新提示徽标。
- **空闲安装机制** — 用户可选择「立即重启安装」或「空闲时自动安装」，空闲安装通过轮询检测窗口失焦状态触发。
- **GitHub Release 服务** — 通过 GitHub API 获取发布日志，在「关于」面板展示版本更新内容。
- **更新状态 Store** — 新增 Pinia store 统一管理更新状态，订阅主进程推送事件。

### 💾 磁盘管理

- **存储用量统计** — 设置 →「磁盘管理」Tab，可视化展示各数据类别（Agent 会话、工作区、数据库、日志、临时文件等）的磁盘占用。
- **分类存储条** — 彩色横向存储条直观展示各类别占比，支持悬停查看详情。
- **一键清理** — 支持按类别清理临时文件和日志，快速释放磁盘空间。

### 🎨 中国传统纹样背景系统

- **9 种传统纹样** — 新增回纹、万字纹、冰裂纹、祥云纹、如意纹、锁子甲、龟背纹、八达晕、落花流水纹共 9 种中国传统纹样可选。
- **墨随纸变** — 纹样颜色基于 `--foreground` 变量的色相和明度，通过 alpha 通道自动适配明暗模式。
- **纹样选择卡片** — 设置 → 外观 → 基础色调下方新增纹样选择横向滚动卡片，实时预览纹样效果。

### 🖼️ 界面风格切换

- **经典 / 现代两种风格** — 新增界面风格切换，经典风格为传统边框分隔布局，现代风格为浮层卡片布局（菜单栏圆角 + 阴影 + 间距），风格偏好持久化到 localStorage。
- **基础色调卡片改版** — 基础色调从圆形色块改为横向滚动卡片布局，每个卡片模拟该色调下的 UI 样式。新增黛蓝、朱砂、松花、藕荷、赭石五种中国传统色。

### 🤖 AI 模型 Logo 系统

- **60+ 模型图标** — Chat 和 Agent 对话中 AI 头像从通用盾牌图标改为对应模型的 Logo，支持 OpenAI GPT 系列、Claude、Gemini、DeepSeek、通义千问、Moonshot、Llama、Grok 等 60+ 主流模型。
- **供应商预设** — 内置主流 AI 供应商的类型、显示名称、默认 Base URL 和预设模型列表，添加模型时自动填充。
- **暗色模式适配** — 部分模型 Logo 提供暗色版本，随主题自动切换。

### 🎙️ 语音识别

- **本地 FunASR 语音识别** — 集成 FunASR llama.cpp / GGUF 运行时，支持 SenseVoice Small、Paraformer、Fun-ASR-Nano 三种本地语音识别模型，预编译二进制随应用打包分发。
- **火山引擎流式语音识别** — 支持接入火山引擎双向流式 WebSocket 语音识别服务，实现边说边出字的实时转写体验。
- **Chat / Agent 语音输入** — 对话输入区新增麦克风图标，录音时实时将转写文字填入输入框。
- **草稿语音输入** — 草稿编辑器支持语音输入弹窗，转写文字可插入光标位置或追加到末尾。
- **语音模型统一管理** — FunASR 模型的下载、选择和管理统一提取到设置页面。

### 📝 对话富内容渲染

- **SVG 图表内联渲染** — LLM 输出的 ` ```widget ` 代码块由 WidgetNode 组件渲染为可视化图表，支持预览 / 源码切换、缩放、全屏、下载为 PNG。渲染前经 DOMPurify 安全净化。
- **Mermaid 图表渲染** — 对话中的 ` ```mermaid ` 代码块渲染为流程图 / 时序图 / 甘特图等，语法错误时自动降级为 `<pre>` 展示原始代码。
- **KaTeX 数学公式** — 对话中的 LaTeX 公式由 KaTeX 渲染为排版精美的数学公式。
- **流式渲染优化** — SVG widget 在 fence 闭合后才渲染，避免流式半成品畸形；Markdown 文本支持 smooth-streaming 平滑流式输出。

### 🗂️ Agent 面板布局系统

- **三栏自适应布局** — Agent 工作区采用「对话 | 代码编辑器 | 文件面板」三栏布局，各栏可拖拽调整宽度。
- **面板左右交换** — 一键切换对话面板与文件面板的左右位置，布局偏好持久化。
- **文件面板折叠** — 工具栏支持折叠 / 展开文件面板，折叠后对话栏获得全部可用宽度。
- **代码编辑器开关** — 按需打开中间编辑器面板。

### 💻 代码编辑模式

- **内置 Monaco 编辑器** — Agent 模式新增内嵌 Monaco 代码编辑器，支持 30+ 语言语法高亮，无需切换外部 IDE 即可查看和编辑项目文件。
- **多标签页编辑** — 支持多文件标签页同时打开，标签页显示文件名和 Git 状态标记（A=新增、M=修改、橙色 M=编辑中未保存）。
- **自动保存** — 文件内容修改后自动触发 1 秒防抖保存。
- **主题联动** — 编辑器主题跟随应用主题色实时切换，从 CSS 变量读取 HSL 值并转换为 Monaco 可用的颜色。
- **跨文件跳转** — JS / TS 文件支持跨文件 `import` 跳转。
- **会话级状态持久化** — 每个 Agent 会话独立维护编辑器打开文件列表和活跃文件。

### 📁 文件模块增强

- **双模式切换** — 文件面板支持「会话文件」和「项目文件」两种模式切换。
- **附加文件夹管理** — 项目模式下可附加外部文件夹（仅引用不复制），支持展开 / 折叠浏览、移除、刷新 Git 状态。
- **Git 状态可视化** — 文件树和附加目录中每个文件 / 文件夹显示 Git 变更标记，文件夹递归聚合子项状态。
- **路径智能省略** — 文件路径层级超过 3 层时自动左侧省略，保留最关键的末尾路径片段。
- **整理网页链接为笔记** — 支持将网页链接内容自动整理为结构化笔记，快速保存和管理网络资料。

### ✏️ Markdown 所见即所得编辑器

- **Tiptap WYSIWYG 编辑器** — 草稿和本地 md 文件编辑从 md-editor-v3 切换为基于 Tiptap 的所见即所得编辑器，自定义 Lucide 图标工具栏。
- **tiptap-markdown 双向转换** — 实现 Markdown ↔ ProseMirror 文档的双向自动转换，编辑时实时序列化为 Markdown 存储。
- **空段落保留** — 自定义段落序列化器，解决 prosemirror-markdown 默认将连续空段落压缩导致多空行丢失的问题。
- **列表样式修复** — 为无序列表和有序列表显式声明 list-style-type，修复 Tailwind Preflight 重置导致的列表标记不显示问题。

### 📋 任务日程与 Todo

- **任务看板** — 任务日程与 Todo 管理模块，支持自动化调度、提醒和日历工作区。
- **定时任务** — 支持在对话中嵌入定时任务标记，Chat 用户消息中渲染定时任务 chip。

## 🚀 优化

### 设置面板

- **设置侧边栏改版** — Tab 按钮增大尺寸和间距，选中态使用 `text-primary` 高亮；「通用设置」移至首位作为默认 Tab。
- **模型配置面板重构** — 从表格布局改为卡片列表布局，每个模型卡片展示 Logo、名称、状态和操作按钮。
- **模型编辑弹窗** — 新增 `ModelEditDialog.vue` 侧边面板式编辑器，支持供应商选择（带 Logo）、自动填充、连通性测试。
- **路由参数支持** — 设置面板支持通过 `?tab=about` 路由参数直接跳转到指定 Tab。

### Agent 对话体验

- **执行过程折叠** — Agent 的 thinking 和 tool_use 过程块自动折叠为可展开的 ProcessBlockGroup，减少视觉噪音。
- **消息统计悬浮指示器** — 用户消息右侧新增悬浮指示器，hover 时预览对应 AI 回复，支持快速跳转。
- **权限与询问弹窗** — Agent 执行中需要权限确认或用户输入时，在对话区域顶部弹出内联弹窗，不打断对话流。
- **用户消息引用 Chip** — Chat 用户消息中的 `@file`、`/skill`、`#mcp`、`&session` 等引用标记渲染为彩色 chip 样式。

### Chat / Agent 对话

- **消息宽度** — 移除 Chat 消息区域的 `max-w-[860px]` 限制，消息宽度自适应容器。
- **对话指示器修复** — 修复 Chat / Agent 对话区域用户消息浮动指示器（rail）的定位与交互问题。
- **模型信息补全** — Agent 模型列表补全 `model_name`、`provider`、`base_url` 字段，支持 Logo 显示。

### 草稿 & Tab 管理

- **草稿底部状态栏** — 草稿编辑器顶部只保留工具栏，底部新增状态栏（左侧标签，右侧"临时记录 · 自动保存"提示）。
- **Tab 顺序固定** — Chat / Agent 切换时同类型标签原位替换而非追加到末尾。
- **草稿永久保留** — 草稿 Tab 不可关闭、不可清除，自动保存防抖 500ms。

### 状态栏

- **版本号交互** — 点击版本号跳转到「关于」面板；有更新时显示蓝色提示徽标。
- **链接修正** — 贡献链接指向实际 GitHub 仓库，文档链接指向官网文档。

### MenuBar 左侧导航

- **Agent 会话恢复** — 无活跃会话时自动选中第一个项目的第一个会话，Tab 恢复时检查会话是否存在并回退。
- **删除图标** — 删除按钮图标从 `Trash2` 改为 `Eraser`，尺寸缩小。

### 启动流程

- **主窗口延迟显示** — 主窗口 `show: false`，由 lifecycle 控制何时显示，避免启动期间出现空白窗口。
- **移除强制全屏** — 移除原先 `setBounds` 将主窗口强制设置为屏幕 80%×70% 的逻辑，主窗口尺寸完全由 config 控制。

### 打包配置

- **移除 OnlyOffice** — 删除 OnlyOffice WASM 运行时及编辑器组件，安装包体积从约 1.2GB 降至约 500MB，Office 文件改为只读预览。
- **asarUnpack 配置** — 新增 `**/*.node`、`node-pty`、`@kutalia/whisper-node-addon`、`better-sqlite3`、`canvas` 到 asarUnpack 列表，确保原生模块正确加载。
- **排除非目标平台二进制** — 各平台 builder 配置排除非目标平台的 onnxruntime-node 二进制（约 55MB）。
- **CI 原生模块重编译** — CI 流水线新增 `node-pty` 到 electron-rebuild 重编译列表。
- **Node 内存优化** — CI 构建设置 `NODE_OPTIONS: --max-old-space-size=4096`，解决前端构建内存溢出（OOM）问题。

### 前端生态

- **shadcn-vue (reka-ui)** — 从 Ant Design Vue 迁移到 shadcn-vue (reka-ui)，统一使用 Radix/shadcn primitives 与主题变量。
- **xterm.js** — 新增 `@xterm/xterm`、`@xterm/addon-fit`、`@xterm/addon-web-links` 依赖，支持终端模拟器。
- **node-pty & node-enigo** — 新增 `node-pty`（伪终端）和 `node-enigo`（远程输入模拟）原生模块依赖。

### Skill 管理

- **禁用 Skill 时 ENOENT 修复** — 修复 `toggleWorkspaceSkill` 在禁用 Skill 时目标目录不存在导致 `renameSync` 报错的问题，现在移动前自动创建目标目录。

### RAG 向量化

- **无模型时安全降级** — 向量嵌入模块在用户未下载 / 选择模型时抛出 `NoVectorModelError`，不再静默回退到硬编码模型。
- **初始化失败容错** — RAG 初始化失败时清空队列，通知前端各文件失败原因，重置初始化状态以便用户下载模型后重新初始化。
