- **产品名称统一** — 将 `productName` 从 `Diting AI` 改为 `Diting`，消除空格导致的打包产物名不一致、GitHub Release asset 文件名编码混乱、`latest-mac.yml` 合并匹配失败等问题

## 修复

- **GitHub Actions 管线修复** — 修复 `npm ci`、`.gitignore` 误伤源码、macOS x64 runner 排队、draft release 查找、重复 Release 等 CI 问题
- **管线 merge Job 简化** — `productName` 去空格后移除了 URL 解码逻辑，产物名统一为 `Diting-mac-{version}-{arch}.zip`

## ⚠️ macOS 安装须知

由于应用未进行 Apple 代码签名和公证，macOS 安装后打开可能提示「"Diting"已损坏，无法打开」。

**解决方法：** 打开终端执行以下命令，然后重新打开应用：

```bash
xattr -cr /Applications/Diting.app
```

或者：打开「系统设置」→「隐私与安全性」→ 底部点击「仍要打开」。
