# v5.0.28

## 新功能

### 多语言国际化（i18n）

- **7 种语言支持**：新增简体中文（zh-CN）、英文（en-US）、日文（ja-JP）、韩文（ko-KR）、葡萄牙语（pt-BR）、西班牙语（es-ES）、印地语（hi-IN）共 7 种语言界面
- **完整覆盖**：所有用户可见的 UI 文本（菜单、按钮、对话、设置、状态栏、空状态、提示信息等）均已国际化，每种语言约 1,700+ 条翻译条目
- **语言自动检测**：首次启动时根据系统语言自动选择界面语言，用户可在设置 → 外观中随时切换
- **语言切换即时生效**：切换语言后界面立即刷新，无需重启应用

### 启动过场动画

- **视频过场页面**：应用启动时先显示过场动画窗口，播放 `diting_loading.mp4` 视频作为背景，待主窗口页面渲染完成后自动切换
- **品牌信息展示**：过场页面左上角展示产品标题（Diting Desktop）、副标题（本地优先的 AI 桌面工作台）、功能描述和 Tips（简单问题用 Chat · 复杂问题用 Agent），带渐变遮罩设计感
- **版权声明**：左下角标注「视频素材版权来自：影视飓风」
- **视频播放策略**：视频播放一遍即停，不循环；视频加载失败时自动降级为旋转动画作为备用
- **尺寸与居中**：过场窗口使用 config 中配置的窗口宽高，并在屏幕居中显示

## 优化

### 启动流程

- **主窗口延迟显示**：主窗口 `show: false`，由 lifecycle 控制何时显示，避免启动期间出现空白窗口
- **移除强制全屏**：移除原先 `setBounds` 将主窗口强制设置为屏幕 80%×70% 的逻辑，主窗口尺寸完全由 `config.default.ts` 的 `windowsOption` 控制，默认 980×850 并居中

### Skill 管理修复

- **禁用 Skill 时 ENOENT 修复**：修复 `toggleWorkspaceSkill` 在禁用 Skill 时，目标目录 `skills-inactive/` 不存在导致 `renameSync` 报 `ENOENT` 错误的问题；现在移动前会自动创建目标目录
