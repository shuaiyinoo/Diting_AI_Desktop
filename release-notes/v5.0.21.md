# Diting AI Desktop v5.0.21 更新

## 修复

- **GitHub Actions 管线修复** — 修复 `npm ci` 因缺少 `package-lock.json` 而失败的问题，改为 `npm install`
- **esbuild 构建修复** — 修复 `.gitignore` 中 `runtime/` 规则误伤 `electron/components/pi/runtime/` 源码目录的问题
- **macOS x64 管线优化** — 将 x64 构建从 `macos-13` 改为 `macos-latest` 交叉编译，4 个平台并行执行
- **latest-mac.yml 合并修复** — 参考 Proma 方案修复 merge Job：使用 `/releases` 列表遍历查找 draft release
- **重复 Release 修复** — 新增 `create-release` Job 在构建前先创建唯一的 draft release，避免 4 个并行 build Job 各自创建 Release 导致重复；最终由 `update-release-notes` Job 将 draft 发布为正式 release

## 下载

- **macOS Apple Silicon** — `Diting AI-mac-5.0.21-arm64.dmg`
- **macOS Intel** — `Diting AI-mac-5.0.21-x64.dmg`
- **Windows** — `Diting AI-Setup-5.0.21.exe`
- **Linux** — `Diting AI-5.0.21.AppImage`
