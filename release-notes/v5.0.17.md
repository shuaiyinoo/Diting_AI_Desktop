# Diting AI Desktop v5.0.17 更新

## 改进

- **License 更新** — 更新为 Apache License 2.0，补充 Copyright 2026 Diting AI 声明
- **README 修订** — 修正仓库地址、下载链接、文档引用路径，统一指向项目实际 GitHub 仓库
- **README.zh-CN 重写** — 完全替换旧的 electron-egg 模板内容，改为 Diting AI Desktop 中文说明文档
- **package.json 规范化** — license 字段从 `Apache` 改为标准 SPDX 标识符 `Apache-2.0`

## 修复

- **GitHub Actions 管线修复** — 修复 `npm ci` 因缺少 `package-lock.json`（项目 `.gitignore` 主动忽略）而失败的问题，改为 `npm install`
- **esbuild 构建修复** — 修复 `.gitignore` 中 `runtime/` 规则误伤 `electron/components/pi/runtime/` 源码目录，导致 `runtime-manager.ts` 和 `runtime-settings.ts` 未提交到仓库、CI 构建报模块找不到的问题；将 `runtime/` 改为 `/runtime/` 仅忽略根目录
