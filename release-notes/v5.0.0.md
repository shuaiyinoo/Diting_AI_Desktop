# Diting AI Desktop v5.0.0 更新

## 新功能

- **Pi Agent 智能代理** — 基于 @earendil-works/pi-coding-agent 的完整 Agent 模式，支持工作区隔离、Skills 技能系统、MCP 工具协议、权限模式和思考深度调节。
- **权限模式切换** — Agent 输入框左下角可切换「完全自动」/「需确认」两种权限模式，需确认模式下对话框显示虚线边框以作视觉区分。
- **思考深度选择** — Agent 输入框左下角可调节思考深度（关闭 / 低 / 中 / 高 / 极高），支持快速切换和滑块精确选择。
- **多会话并行** — Agent 模式支持多个会话同时运行，通过标签栏切换，后台会话不丢失流式输出。
- **协作子 Agent** — 复杂任务可拆分为可追踪的协作子 Agent，消息流中展示调用过程和结果。
- **用量统计** — LLM 调用用量记录与费用估算，按时间、文件夹、模块多维度统计。

## 优化

- **Agent 工具栏布局优化** — 权限模式和思考深度图标移至左下角，模型选择移至右侧，发送按钮缩小为与图标一致的尺寸。
- **Proma 风格侧边栏** — 可折叠侧边栏，渐变背景 + 圆角菜单，活跃态蓝色渐变 + 阴影。

## Bug 修复

- 修复 better-sqlite3 在 Electron 39 下的原生模块兼容性问题。
- 修复文件同步服务在高频文件变更时的重复向量化问题。
