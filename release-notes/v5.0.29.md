# v5.0.29

## 新功能

### Agent 面板布局系统

- **三栏自适应布局**：Agent 工作区采用「对话 | 代码编辑器 | 文件面板」三栏布局，对话栏 flex-1 自适应，编辑器和文件面板固定宽度且可拖拽调整
- **面板左右交换**：工具栏新增面板交换按钮（ArrowLeftRight 图标），一键切换对话面板与文件面板的左右位置，布局偏好持久化到 localStorage
- **文件面板折叠**：工具栏新增文件面板折叠/展开按钮（PanelRightClose/Open 图标），折叠后对话栏获得全部可用宽度
- **代码编辑器开关**：工具栏新增代码编辑器显隐按钮（Code2 图标），按需打开中间编辑器面板

### 代码编辑模式

- **内置 Monaco 编辑器**：Agent 模式新增内嵌 Monaco 代码编辑器，支持 30+ 语言语法高亮（JS/TS/Vue/Python/Go/Java/Rust 等），无需切换外部 IDE 即可查看和编辑项目文件
- **多标签页编辑**：编辑器支持多文件标签页同时打开，标签页显示文件名和 Git 状态标记（A=新增、M=修改、橙色 M=编辑中未保存），点击切换活跃文件
- **自动保存**：文件内容修改后自动触发 1 秒防抖保存，保存到会话文件或项目原始路径
- **主题联动**：编辑器主题跟随应用主题色实时切换（亮色/暗色 + 基础色调），从 CSS 变量读取 HSL 值并转换为 Monaco 可用的颜色
- **跨文件跳转**：JS/TS 文件支持跨文件 `import` 跳转，通过自定义 DefinitionProvider 解析相对路径并打开目标文件
- **会话级状态持久化**：每个 Agent 会话独立维护编辑器打开文件列表和活跃文件，切换会话时自动保存和恢复编辑器状态
- **文件来源双向支持**：从文件面板的会话文件或项目附加文件夹打开文件到编辑器，二进制文件自动跳过并提示

### 对话富内容渲染

- **SVG 图表内联渲染**：LLM 输出的 ` ```widget ` 代码块（内含完整 `<svg>` 标签）由 WidgetNode 组件渲染为可视化图表，支持预览/源码切换、缩放、全屏展开、复制 SVG 源码、下载为 PNG
- **DOMPurify 安全净化**：SVG 渲染前经过 DOMPurify 净化，禁用 `<script>` 标签和事件处理器（onload/onclick/onerror 等），保留 class 属性和内联 `<style>` 标签以支持主题跟随
- **CSS 变量主题映射**：WidgetNode 容器定义语义化 CSS 变量（`--w-text-primary`、`--w-border-primary`、`--w-accent` 等），LLM 产出的 SVG 引用这些变量即可自动适配亮/暗模式和主题色
- **Mermaid 图表渲染**：对话中的 ` ```mermaid ` 代码块由 markstream-vue 渲染为流程图/时序图/甘特图等，支持复制、全屏、缩放控件和交互操作
- **KaTeX 数学公式**：对话中的 LaTeX 公式由 KaTeX 渲染为排版精美的数学公式
- **渲染错误兜底**：Mermaid 语法错误时自动降级为 `<pre>` 展示原始代码，不抛默认报错打断对话流
- **流式渲染优化**：SVG widget 在 fence 闭合后才渲染（loading 延迟），避免流式半成品畸形；Markdown 文本支持 smooth-streaming 平滑流式输出

### 文件面板增强

- **双模式切换**：文件面板顶部支持「会话文件」和「项目文件」两种模式切换，会话文件显示当前会话目录下的文件，项目文件显示项目根目录和附加文件夹
- **附加文件夹管理**：项目模式下可附加外部文件夹（仅引用不复制），支持展开/折叠浏览、移除附加文件夹、刷新 Git 状态
- **Git 状态可视化**：文件树和附加目录中每个文件/文件夹显示 Git 变更标记——红色 A（新增/未跟踪）、绿色 M（已修改）、橙色 M（编辑中未保存），文件夹递归聚合子项状态
- **路径智能省略**：文件路径层级超过 3 层时自动左侧省略，保留最关键的末尾路径片段

## 优化

### Agent 对话体验

- **执行过程折叠**：Agent 的 thinking 和 tool_use 过程块（非 TaskCreate/TaskUpdate）自动折叠为可展开的 ProcessBlockGroup，减少视觉噪音
- **消息统计悬浮指示器**：用户消息右侧新增悬浮指示器，hover 时预览对应 AI 回复，支持快速跳转
- **权限与询问弹窗**：Agent 执行中需要权限确认或用户输入时，在对话区域顶部弹出内联弹窗（AgentPermissionPopup / AgentAskUserPopup），不打断对话流
