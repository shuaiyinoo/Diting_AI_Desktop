# Diting AI Desktop v5.1.2 更新

> 本次更新为重大交互升级版本，全面重构了 Tab 导航系统，新增 Agent 改动文件 diff 对比视图，并优化了自动更新、面板布局和会话状态保持等多项体验。

---

## ✨ 新功能

### 📑 全新 Tab 导航系统

将原有的路由跳转式导航重构为**持久化 Tab 系统**，所有页面均以 Tab 形式在右侧区域打开，支持多 Tab 共存与状态保持。

- **多类型 Tab 共存** — 草稿、Chat 会话、Agent 会话、文件查看器、文件管理、OCR 录入/归集、任务日程、技能、设置，各类型 Tab 独立管理，同类型替换、不同类型共存。
- **文件夹独立 Tab** — 每个文件夹打开为独立 Tab，标题格式为 `文件夹名 + 平台标识`（如 `文档 SMB`、`项目 LOC`），支持多个文件夹 Tab 同时打开。
- **工具页面 Tab 化** — 文件管理、OCR 录入识读、OCR 归集查阅、任务日程、技能、设置等工具页面全部改为 Tab 形式，不再退出 Tab 模式。
- **Tab 关闭按钮始终可见** — Tab 上的关闭按钮不再仅在 hover 时显示，始终可见，提升操作效率。
- **Tab 自动滚动到可见区域** — 切换或新增 Tab 时自动滚动 Tab 栏，确保当前活跃 Tab 始终在视野内。
- **状态持久化** — Tab 状态通过 `localStorage` 持久化，应用重启后自动恢复上次打开的 Tab 列表和活跃 Tab。

### 🔀 Agent 改动文件（Changed Files）

Agent 模式文件面板新增第三个 Tab —— "改动文件"，展示附加文件夹中所有 Git 变更文件。

- **Tab 样式统一** — "会话文件 / 项目文件 / 改动文件" 三个 Tab 使用统一的 Tab 样式，不可关闭，支持左右滚动。
- **变更文件列表** — 按附加文件夹分组，每个文件夹下展示有 Git 变更的文件列表，显示文件名、状态标签（A/M/S/R）和行数增减（`+N` / `-N`）。
- **Diff 对比视图** — 点击改动文件在代码编辑器中打开 Monaco DiffEditor 并排对比视图，左侧为 HEAD 版本完整内容，右侧为当前工作区内容，清晰展示新增行（绿色）、删除行（红色）和未变更行，支持语法高亮。
- **行数增减统计** — 后端通过 `git diff --numstat` 获取每个变更文件的增删行数，包括未跟踪文件的特殊处理。
- **会话切换自动刷新** — 切换 Agent 会话或 Agent 执行完成后自动刷新改动文件列表，数据实时同步。

### 🌐 自动更新国内加速

- **GitHub 代理下载** — 自动检测中国大陆时区（UTC+8），检测到更新后通过 `gh-proxy` 代理下载 GitHub Release 产物，解决国内下载超时/失败问题。
- **Provider 层面 URL 改写** — 在 `electron-updater` 的 `provider.resolveFiles` 层面修改下载 URL，确保 `doDownloadUpdate` 使用代理地址。

## 🚀 优化

### 会话状态保持（KeepAlive）

- **Chat 会话** — 切换 Chat 会话时保存当前会话的输入框草稿和滚动位置，切回时自动恢复，不再重置页面状态。
- **Agent 会话** — 使用固定 Tab ID 复用同一组件实例，切换会话时组件不销毁，保持编辑器文件列表、文件树展开状态等上下文。
- **文件查看器** — 多文件查看器 Tab 使用 `v-show` 循环渲染替代 `v-if` 条件渲染，所有 Tab 的组件实例常驻内存，切换时保持滚动位置和选中状态。
- **文件管理 Tab** — 引入组件级本地状态（`localSelectedFile`、`localSelectedFileId`），每个文件夹 Tab 独立管理文件选中状态，切换 Tab 不丢失选中文件。

### Agent 三栏布局宽度约束

- **Chat 面板最小宽度保护** — 当文件面板、代码编辑器、Chat 面板三栏同时显示时，约束固定面板总宽度不超过容器宽度减去最小 Chat 宽度（300px），防止 Chat 面板被挤压到不可见。
- **自动约束时机** — 拖拽分隔条、打开/关闭面板、窗口大小变化时自动触发宽度约束。
- **窗口 resize 监听** — 组件挂载时注册 `resize` 监听，卸载时自动清理。

### 文件面板 Tab 滚动

- 文件面板顶部"会话文件 / 项目文件 / 改动文件" Tab 栏在窄宽度时支持左右滚动，隐藏滚动条保持视觉整洁。

## 🐛 Bug 修复

### `v-loading` 指令未注册导致界面卡死

- **问题** — 文件 Tab 打开时触发 `[Vue warn]: Failed to resolve directive: loading`，导致整个界面卡死。
- **修复** — 移除 `v-loading` 自定义指令，替换为条件渲染的 `Loader2` 加载动画，使用 `absolute inset-0` 居中覆盖。

### 改动文件列表数据竞态条件

- **问题** — 会话切换时"改动文件"不刷新或数据错误，必须手动点击"项目文件"再切回"改动文件"才能正确显示。
- **根因** — `loadChangedFiles` 依赖 `attachedDirs`（项目附加目录列表），但 `loadFileTree` 在 `mode='session'` 或 `mode='changed'` 时后端返回空 `attachedDirs`，覆盖了正确的项目级数据。
- **修复** — 新增 `ensureAttachedDirs()` 函数，始终用 `mode='project'` 获取最新的项目附加目录，在会话切换和 Agent 完成后优先调用，确保 `loadChangedFiles` 读到正确的附加目录。

### Diff 视图缺少"未变更"状态

- **问题** — Diff 对比视图只显示删除行和新增行两种状态，大量未变更行被误判为"新增"（全绿）。
- **根因** — 之前从 git diff 的 unified diff 文本中解析重建原始内容，但 diff 只包含变更行和少量上下文行，无法还原完整文件。
- **修复** — 新增后端 `getFileContentFromHead()` 函数，通过 `git show HEAD:filePath` 获取 HEAD 版本的完整文件内容，前端直接使用作为 DiffEditor 的 original model，Monaco 自行计算三种状态。

## 🔧 后端改动

### Git 服务增强（`git-service.ts`）

- 新增 `GitDiffStat` 接口，包含 `insertions` 和 `deletions` 字段。
- `getGitStatus` 新增 `diffStat` 字段，通过 `git diff --numstat` 获取行数增减统计，未跟踪文件通过 `git diff --no-index` 单独处理。
- 新增 `getFileContentFromHead()` — 通过 `git show HEAD:path` 获取文件在 HEAD 版本的完整内容。
- 新增 `getFileDiff()` — 获取文件的 unified diff 输出。

### PiAgent 控制器（`piAgent.ts`）

- `fileOperation` 新增 `getDiff` action，返回 `{ diff, originalContent }`，同时提供 diff 文本和 HEAD 版本完整内容。
