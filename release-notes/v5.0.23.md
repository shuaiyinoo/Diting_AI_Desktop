# v5.0.23

## 修复

### CI 打包前端空白页问题（核心修复）

- **根因**：`frontend/` 目录有独立的 `package.json` 和依赖（vite、vue 等），但 CI 管线只在根目录执行 `npm install`，未安装前端依赖
- **现象**：CI 打包的 dmg 仅 411MB（本地 1.29GB），安装后前端页面空白
- **修复**：在所有构建 Job（macOS ARM64/x64、Linux、Windows）中新增 `安装前端依赖` 步骤（`cd frontend && npm install`）
- **新增构建产物验证**：在每个平台打包前检查 `public/dist/index.html` 是否存在，如果前端构建失败则立即终止 CI，避免打包出无效产物

### macOS ARM64 asar 配置不一致

- `builder-mac-arm64.json` 的 `asar` 为 `false`，与其他平台配置（`true`）不一致
- 统一为 `asar: true`，确保所有平台一致的打包行为
