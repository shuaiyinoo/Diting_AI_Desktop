# v5.0.25

## 优化

### 移除 OnlyOffice 编辑器，大幅缩减安装包体积

- **移除 OnlyOffice WASM 运行时**：删除 `frontend/public/onlyoffice/` 目录（含 9.3.0.134 版本 SDK、字体、web-apps 等全部静态资源），安装包体积从约 1.2GB 降至约 500MB
- **移除 OnlyOfficeEditor 组件**：删除 `frontend/src/components/file/OnlyOfficeEditor.vue`，文件模块不再依赖 OnlyOffice iframe 编辑器
- **统一文件预览**：`.docx` / `.xlsx` / `.pptx` 等 Office 文件改为仅使用 `@file-viewer/vue3-full` 进行只读预览，不再提供编辑功能
- **移除 FilePreviewPanel 编辑按钮**：预览面板不再显示编辑入口，纯预览模式
- **清理主进程代码**：删除 `electron/controller/file.ts` 中的 `createFile`、`saveFileData` 方法及 `BLANK_TEMPLATES` 常量（均依赖 OnlyOffice 模板文件）

### 打包配置优化：排除非目标平台二进制

- 在 `builder-mac-arm64.json` / `builder-mac.json` 中排除 `onnxruntime-node` 的 Linux 和 Windows 平台二进制（约 55MB）
- 在 `builder.json`（Windows）中排除 Linux 和 macOS 平台二进制
- 在 `builder-linux.json` 中排除 Windows 和 macOS 平台二进制
