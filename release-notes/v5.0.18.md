# Diting AI Desktop v5.0.18 更新

## 修复

- **GitHub Actions 管线修复** — 修复 `npm ci` 因缺少 `package-lock.json` 而失败的问题，改为 `npm install`
- **esbuild 构建修复** — 修复 `.gitignore` 中 `runtime/` 规则误伤 `electron/components/pi/runtime/` 源码目录，导致 `runtime-manager.ts` 和 `runtime-settings.ts` 未提交到仓库、CI 构建报模块找不到的问题；将 `runtime/` 改为 `/runtime/` 仅忽略根目录
- **macOS x64 管线优化** — 将 x64 构建从 `macos-13`（Intel runner，排队严重）改为 `macos-latest`（ARM64 runner）交叉编译，4 个平台构建全部并行执行不再等待
- **latest-mac.yml 合并修复** — 修复 merge Job 中 zip 文件名匹配逻辑与实际 `artifactName` 模板不一致导致找不到产物的问题
- **Release 产物冲突修复** — 同一 tag 重复发布导致 GitHub Release 上传冲突，升级版本号至 5.0.18 重新发布
