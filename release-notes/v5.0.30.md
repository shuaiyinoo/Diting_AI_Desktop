# v5.0.30

## 新功能

### 文件模块全新改版

- **文件面板重构**：文件管理模块全面重新设计，界面交互更简洁高效
- **整理网页链接为笔记**：支持将网页链接内容自动整理为结构化笔记，快速保存和管理网络资料

### 引入语音识别模型

- **本地 FunASR 语音识别**：集成 FunASR llama.cpp / GGUF 运行时，支持 SenseVoice Small、Paraformer、Fun-ASR-Nano 三种本地语音识别模型
- **模型管理**：设置中支持下载和管理 FunASR 模型，支持国内镜像源（hf-mirror.com）自动切换，区分 Whisper 和 FunASR 模型列表
- **跨平台二进制内置**：FunASR 预编译二进制随应用打包分发，无需 Python 环境，支持 macOS（arm64/x64）、Windows、Linux
- **VAD 内置分段**：利用 FunASR CLI 内置 fsmn-vad 自动对长音频进行语音分段，无需 JS 层切割
- **Chat/Agent 语音输入**：对话输入区新增麦克风图标，录音时实时将转写文字填入输入框，点击录音条可随时停止
- **草稿语音输入**：草稿编辑器支持语音输入弹窗，转写文字可插入光标位置或追加到末尾
- **火山引擎流式语音识别**：支持接入火山引擎双向流式 WebSocket 语音识别服务，实现边说边出字的实时转写体验

### Chat/Agent 对话指示器修复

- **消息导航指示器修复**：修复 Chat/Agent 对话区域用户消息浮动指示器（rail）的定位与交互问题，hover 时正确预览对应 AI 回复，点击准确跳转目标消息

## 优化

- **Agent 文件面板默认折叠**：Agent 模式右侧文件面板默认关闭，减少视觉干扰，需要时通过工具栏按钮展开
- **语音录音条交互简化**：录音条只显示脉动指示点和"录音中"状态，转写文字实时填入上方输入框，不再在录音条上显示
- **草稿语音弹窗样式优化**：去除弧线过渡 CSS，弹出框使用简洁圆角设计，与按钮保持间距
