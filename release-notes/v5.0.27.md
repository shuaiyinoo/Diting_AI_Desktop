# v5.0.27

## 新功能

### 自动更新系统重构

- **全新自动更新架构**：重写 `electron-updater` 集成，支持状态机式更新流程（idle → checking → available → downloading → downloaded），主进程实时推送状态到渲染进程
- **后台静默下载**：检测到新版本后自动后台下载，下载完成后在状态栏显示更新提示徽标（蓝色圆点 + 高亮版本号）
- **空闲安装机制**：用户可选择「立即重启安装」或「空闲时自动安装」，空闲安装通过轮询检测窗口失焦状态触发
- **GitHub Release 服务**：新增 `github-release-service.ts`，通过 GitHub API 获取发布日志，在「关于」面板展示版本更新内容
- **更新状态 Pinia Store**：新增 `frontend/src/stores/updater.js`，统一管理更新状态，订阅主进程推送事件
- **关于面板**：新增设置 →「关于/更新」Tab，展示应用信息（版本、运行时、开源协议、项目地址）和软件更新卡片（检查更新、下载进度、安装操作）

### 磁盘管理

- **存储用量统计**：新增设置 →「磁盘管理」Tab，可视化展示各数据类别（Agent 会话、工作区、数据库、日志、临时文件等）的磁盘占用
- **分类存储条**：彩色横向存储条直观展示各类别占比，支持悬停查看详情
- **一键清理**：支持按类别清理临时文件和日志，快速释放磁盘空间
- **后端存储服务**：新增 `electron/service/storage-service.ts` 和 `electron/controller/storage.ts`，递归计算目录大小、安全清理文件

### 模型 Logo 系统

- **AI 模型图标**：Chat 和 Agent 对话中 AI 头像从通用盾牌图标改为对应模型的 Logo，支持 60+ 主流模型（OpenAI GPT 系列、Claude、Gemini、DeepSeek、通义千问、Moonshot、Llama、Grok 等）
- **供应商预设**：新增 `provider-presets.js`，内置主流 AI 供应商的类型、显示名称、默认 Base URL 和预设模型列表，添加模型时自动填充
- **模型选择器增强**：Chat 和 Agent 底部模型选择下拉框显示模型 Logo + 名称，选中态同步展示 Logo
- **暗色模式适配**：部分模型 Logo 提供暗色版本（`*_dark.png`），随主题自动切换

### 中国传统纹样背景系统

- **9 种传统纹样**：新增回纹、万字纹、冰裂纹、祥云纹、如意纹、锁子甲、龟背纹、八达晕、落花流水纹共 9 种中国传统纹样可选
- **墨随纸变**：纹样颜色基于 `--foreground` 变量的色相和明度，通过 alpha 通道自动适配明暗模式（亮色 0.05 透明度，暗色 0.04），确保视觉舒适
- **局部应用**：纹样仅叠加在顶部菜单栏、左侧导航栏、底部状态栏三个控件上，通过 `.pattern-surface` 类 + `::before` 伪元素实现，不影响交互
- **60% 缩放**：纹样尺寸缩小至原始 60%，提升精致感
- **纹样选择卡片**：设置 → 外观 → 基础色调下方新增纹样选择横向滚动卡片，实时预览纹样效果

### 基础色调卡片改版

- **横向滚动卡片**：基础色调从圆形色块改为横向滚动卡片布局，每个卡片模拟该色调下的 UI 样式（标题行、正文行、按钮、输入框）
- **新增中国传统色调**：基础色调新增黛蓝、朱砂、松花、藕荷、赭石五种中国传统色，主色同步新增对应选项
- **主色自动换行**：主色选择区从单行排列改为自动换行布局，适配更多色选

## 优化

### 设置面板

- **设置侧边栏改版**：Tab 按钮增大尺寸和间距，选中态使用 `text-primary` 高亮，整体视觉更清晰
- **路由参数支持**：设置面板支持通过 `?tab=about` 路由参数直接跳转到指定 Tab，状态栏版本号点击可跳转到「关于」面板
- **模型配置面板重构**：从表格布局改为卡片列表布局，每个模型卡片展示 Logo、名称、状态和操作按钮；新增「Diting Cloud 模型」入口（BETA 标记）
- **模型编辑弹窗**：新增 `ModelEditDialog.vue` 侧边面板式编辑器，支持供应商选择（带 Logo）、自动填充 Base URL 和预设模型、连通性测试
- **模型测试弹窗**：新增 `ModelTestDialog.vue`，展示连通性测试结果（成功/失败 + 延迟）

### MenuBar 左侧导航

- **Agent 会话恢复**：无活跃会话时自动选中第一个项目的第一个会话，Tab 恢复时检查会话是否仍存在并回退
- **删除图标**：文件夹/对话/项目/会话的删除按钮图标从 `Trash2` 改为 `Eraser`，尺寸缩小

### Chat / Agent 对话

- **消息宽度**：移除 Chat 消息区域的 `max-w-[860px]` 限制，消息宽度自适应容器
- **Agent 会话恢复**：修复 Agent 模式 Tab 恢复时消息未加载和滚动位置丢失的问题
- **模型信息补全**：Agent 模型列表补全 `model_name`、`provider`、`base_url` 字段，支持 Logo 显示

### 状态栏

- **版本号交互**：点击版本号从直接检查更新改为跳转到「关于」面板；有更新时显示蓝色提示徽标
- **链接修正**：贡献链接指向实际 GitHub 仓库，文档链接指向官网文档
