# Diting AI Desktop 教程

> 编辑时版本：v5.0.0
> 框架：electron-egg v5

## 写在开始之前

欢迎使用 Diting AI Desktop（谛听 AI 桌面客户端）。这是一款本地优先的桌面 AI 助手，把文件管理、RAG 知识库问答、Agent 智能代理和多轮对话放在同一个应用里。

本教程会从下载安装讲到核心功能使用，帮助你快速上手。

## 下载和安装

### 下载

从 GitHub Releases 下载对应平台安装包：

- **macOS Apple Silicon** — `.dmg` (ARM64)
- **macOS Intel** — `.dmg` (x64)
- **Windows** — `..exe` (64-bit)
- **Linux** — `.AppImage`

### 安装

- **macOS**：双击 `.dmg` 拖入 Applications
- **Windows**：双击 `.exe` 按提示安装（推荐安装到 C 盘）
- **Linux**：双击 `.AppImage` 或命令行执行

## 首次配置

### 1. 配置 LLM 模型

进入 **设置 > 模型配置**（或 `/adjust` 页面）：

1. 点击「新增模型」
2. 填写：
   - **名称**：自定义标识（如 `GPT-4o`）
   - **Base URL**：API 地址（如 `https://api.openai.com/v1`）
   - **API Key**：你的密钥
   - **模型名称**：如 `gpt-4o`、`deepseek-chat` 等
3. 点击「测试连接」确认可用
4. 点击「启用」激活该模型

> 支持任何 OpenAI 兼容协议的 API，包括 OpenAI、DeepSeek、Kimi、智谱、通义千问等。

### 2. 授权知识库文件夹

进入 **文件管理**（或 `/file` 页面）：

1. 点击「授权文件夹」
2. 选择一个包含文档的文件夹
3. 应用会自动扫描文件并开始向量化

> 向量化过程在本地执行，使用 Qwen ONNX 嵌入模型，无需联网。

### 3. 等待向量化完成

在文件管理页面可以看到每个文件的向量化进度。完成后文件状态变为「就绪」，即可用于知识库问答。

## 核心功能

### 知识库问答（QA）

进入 **知识库问答**（或 `/qa` 页面）：

1. 在输入框输入问题
2. 系统会从已授权的文档中混合检索（向量 + 关键字）
3. LLM 基于检索到的证据生成回答
4. 回答下方展示引用来源和证据片段

**适合场景**：
- 基于文档库的问答
- 需要精确引用原文的严肃工作
- 法律、科研、企业知识库查询

### AI 对话（Chat）

进入 **AI 对话**（或 `/chat` 页面）：

1. 在输入框输入消息
2. 模型流式返回回答
3. 支持多轮对话和上下文记忆

**适合场景**：
- 日常问答、翻译、润色
- 轻量代码讨论
- 快速验证想法

### Agent 智能体

进入 **Agent**（或 `/agent` 页面）：

#### 创建工作区

1. 在左侧创建新工作区（如「我的项目」）
2. 工作区隔离 Skills 和 MCP 配置

#### 配置 Skills

1. 进入工作区的 Skills 管理
2. 启用/禁用内置 Skills
3. 创建自定义 Skill（Markdown 格式）

#### 配置 MCP

1. 进入工作区的 MCP 管理
2. 添加 MCP Server（stdio / HTTP）
3. Agent 可调用 MCP 工具

#### 使用 Agent

1. 在输入框输入任务描述
2. Agent 会自主执行（读取文件、运行命令、创建文件等）
3. **权限模式**（左下角）：
   - ⚡ **完全自动**：所有工具调用自动允许
   - 🛡️ **需确认**：工具调用需用户确认（对话框显示虚线边框）
4. **思考深度**（左下角）：点击切换 off / high，长按弹出滑块选择 low / medium / high / xhigh
5. 右侧选择模型和发送

**适合场景**：
- 修改、创建、整理本地文件
- 多步骤任务和调研报告
- 使用 Skills、MCP、Shell 等外部工具
- 需要权限确认的工作

### 文件管理

进入 **文件管理**（或 `/file` 页面）：

- **授权文件夹**：添加/移除文档源
- **文件浏览**：树形结构展示，支持 Office/PDF 预览
- **自动同步**：文件变更后自动重新向量化
- **RAG 进度**：查看每个文件的处理状态

### 用量统计

进入 **用量统计**（或 `/metrics` 页面）：

- 总提问次数、平均延迟、Token 用量
- 基于模型定价的费用估算
- 按时间趋势、文件夹、模块分类统计

## 进阶使用

### Agent 权限模式

Agent 输入框左下角有两个图标：

1. **权限模式切换**（闪电/盾牌图标）
   - 完全自动：Agent 直接执行所有操作，无需确认
   - 需确认：每次工具调用弹出确认面板，输入框显示虚线边框

2. **思考深度选择**（大脑图标）
   - 点击快速切换：off ↔ high
   - 长按弹出滑块：关闭 / 低 / 中 / 高 / 极高
   - 思考深度越高，Agent 推理越深入但速度越慢

### 多会话并行

- Agent 模式支持多个会话同时运行
- 通过顶部标签栏切换会话
- 后台会话不会丢失流式输出

### Skills 技能系统

Skills 是可复用的提示词模板和工作流程：

- 内置 Skills：文档解析、PPT 生成、代码执行等
- 自定义 Skills：在工作区 `skills/` 目录创建 Markdown 文件
- 在 Agent 输入中通过 `/skill-name` 引用

### MCP 工具协议

MCP（Model Context Protocol）让 Agent 接入外部工具：

- **stdio MCP**：启动本地进程作为工具服务
- **HTTP MCP**：连接远程工具服务
- 每个工作区独立配置 MCP

## 常见问题

### 向量化速度慢

- 向量嵌入使用本地 ONNX 模型，首次加载需要初始化
- 大文件（100页+）需要较长时间切片和嵌入
- 可以在文件管理页面查看进度

### Agent 无法执行命令

- 检查权限模式设置
- 需确认模式下，Agent 会等待用户确认后才执行
- 完全自动模式下，Agent 直接执行

### 模型连接失败

- 检查 Base URL 是否正确（需包含 `/v1` 等路径）
- 检查 API Key 是否有效
- 使用「测试连接」功能排查

### better-sqlite3 报错

- 运行 `npm run re-sqlite` 重建原生模块
- 确保 Node.js 版本 >= v20
