SKILL.md

DOCX Skill

Use this skill whenever the user wants to create, read, edit, or manipulate Word documents (.docx files). This includes:

  • Creating new Word documents from scratch or templates
  • Reading content from existing .docx files
  • Modifying existing documents (text, formatting, structure)
  • Extracting text, tables, images from documents
  • Converting between formats

When to use

Trigger this skill when the user mentions .docx, Word document, or asks to generate/read/edit Office documents.

Workflow

  • Identify the user's intent (create / read / edit / extract)
  • Load the appropriate helper script from examples/
  • Execute with proper error handling
  • Validate output before returning to user
