# Diting AI Desktop 产品思考与路线图

> 版本：Draft 1
> 日期：2026-08
> 范围：Diting AI Desktop 桌面客户端的产品方向与功能规划

## 背景

Diting AI Desktop 是 Diting AI 产品矩阵的桌面客户端，基于 electron-egg v5 框架构建。项目受 [Proma](https://github.com/ErlichLiu/Proma) 开源项目启发，在 Agent 交互设计和 UI 风格上参考了其优秀实践。

Diting AI 的核心定位是**本地优先的 AI 工作台**：简单问题用对话，文档问题用知识库问答，复杂任务用 Agent。

## 当前阶段

### 已实现功能

- ✅ **文件管理与 RAG**：授权文件夹、自动向量化、混合检索、引用追踪
- ✅ **知识库问答**：基于本地文档的 RAG 问答，证据等级评估
- ✅ **Pi Agent 智能代理**：工作区隔离、Skills、MCP、权限模式、思考深度
- ✅ **多轮对话**：多模型、流式输出、上下文记忆
- ✅ **LLM 模型管理**：多模型配置、连接测试、用量统计
- ✅ **跨平台**：Windows / macOS / Linux

### 核心优势

1. **本地优先**：嵌入、检索、存储全部本地执行，数据隐私有保障
2. **混合检索**：向量相似度 + 关键字搜索双重召回，比单一检索更准确
3. **Agent + RAG 融合**：Agent 可调用知识库检索工具，结合文档上下文执行任务
4. **企业级框架**：基于 electron-egg v5，已在多行业验证

## 接下来的方向

### 方向一：Agent 能力增强

**目标**：让 Agent 更智能、更可控、更高效。

- **计划模式**：Agent 先输出执行计划，用户确认后再执行
- **后台任务**：长任务后台运行，完成后通知用户
- **协作子 Agent**：复杂任务自动拆分，多个子 Agent 并行执行
- **文件检查点**：Agent 修改文件前创建快照，支持回退
- **自定义工具保存**：Agent 自动将常用操作固化为可复用工具

### 方向二：知识库能力增强

**目标**：让知识库更智能、更全面、更易用。

- **多格式支持**：Excel、PPT、图片（OCR）解析
- **增量更新**：文件变更后只重新处理变更部分，不重建整个索引
- **多知识库**：支持创建多个独立知识库，按场景隔离
- **知识图谱**：基于 Neo4j 的实体关系抽取与图谱问答
- **引用增强**：引用片段支持跳转原文、上下文展开

### 方向三：用户体验提升

**目标**：让交互更丝滑、更直觉、更高效。

- **全局快捷键**：快速唤起问答窗口
- **语音输入**：支持语音转文字输入
- **桌面通知**：Agent 任务完成、权限请求等场景的桌面通知
- **暗色模式**：完整的暗色主题支持
- **多语言**：英文界面支持

### 方向四：Diting AI 生态融合

**目标**：与 Diting AI 其他组件深度协同。

- **Diting_AI_Api 融合**：连接后端 API 服务，使用 Neo4j GraphRAG 能力
- **Diting_AI_Index 融合**：接入搜索引擎服务，增强大规模文档检索
- **Diting_AI_Web 融合**：桌面端与 Web 端数据同步
- **远程访问**：通过飞书/钉钉/微信机器人远程触发 Agent

## 非目标

当前阶段不做：

- 云端数据存储（保持本地优先）
- 插件市场（先完善核心能力）
- 通用 Cron 表达式编辑器（用自然语言替代）
- 无需用户授权的全自动写文件/执行命令

## 设计原则

### 本地优先

所有 AI 能力（嵌入、检索、存储）本地执行，数据不上传云端。这是 Diting 的核心承诺。

### 可见自动化

Agent 的所有操作必须可见：
- 为什么执行
- 读取/修改了什么
- 执行结果是什么
- 如何暂停、撤销

### 最小权限

默认只读。写入、执行命令、联网需要明确权限边界。权限模式（完全自动 / 需确认）让用户自由选择信任程度。

### 渐进增强

先做好核心功能（文件管理 → RAG 问答 → Agent），再逐步增加高级能力。不追求一步到位。
